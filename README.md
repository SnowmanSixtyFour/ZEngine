### Z Engine is a 2D game engine, made with [MonoGame](https://monogame.net/).

# About
Z Engine started development in January 2026 for fun. Over the development of smaller game jam projects, it has increased in features and scope.

Now, it has evolved into a full game engine, providing the essentials for 2D game development.

### Made with Z Engine
Below are a list of games made with Z Engine.
* [Between the Lines](https://github.com/SnowmanSixtyFour/BetweenTheLines)
* [ESCAPEAWAY!](https://github.com/SnowmanSixtyFour/EscapeawaySource)
* [LudumRPG](https://github.com/SnowmanSixtyFour/LudumRPG) (working name)
